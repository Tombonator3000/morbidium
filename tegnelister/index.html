Tegnelister

Alt Morbidium fortsatt mangler bilde til, samlet i ark som ChatGPT kan tegne i én vending. Hver liste er én samtale. Hvert ark er én PNG med ferdig filnavn.

Slik gjør du det

  1. Start en ny samtale i ChatGPT og lim inn stilblokken under. Bruk samme samtale for hele lista.
  2. For hvert ark: last opp malen fra mappa maler/ i repoet (står ved arket) og referansebildet hvis det står et, og lim inn prompten.
  3. Last ned resultatet som PNG og gi det nøyaktig filnavnet som står ved arket.
  4. Last fila opp til gpt-grafikk/ i repoet og commit til main. Spillet klipper, renser og bygger det inn av seg selv.
